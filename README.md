# DataMind · 数据分析 Agent

一个纯静态（无需构建）的 Web 应用：上传或粘贴数据，用自然语言进行 **数据查询、趋势分析、异常识别、指标对比**，自动生成分析结论与可视化图表。

## 功能

- **数据接入**：CSV / TSV / JSON / Excel 上传，或直接粘贴文本；内置示例数据集（零售明细）一键载入；自动推断数值 / 日期 / 文本字段。
- **自然语言分析**（四类意图自动识别）：
  - **查询**：TopN、筛选、按维度聚合（柱状 / 饼图）。
  - **趋势**：按月 / 周 / 天 / 年粒度，含环比、线性回归与波动点。
  - **异常识别**：IQR / Z-Score，含偏离度与维度归因，散点图带阈值线。
  - **对比**：排名、占比、离散度（变异系数 CV）。
- **自动产出**：指标卡片 + 3~5 条结论（含具体数字与建议）+ ECharts 图表（折线 / 柱状 / 饼图 / 异常散点）+ 明细表；支持复制摘要、导出 CSV、分析历史回放。
- **大模型接入**：顶栏「模型」可填任意 OpenAI 兼容的 Base URL + Key + 模型名（密钥仅存本机浏览器，直连服务商）。大模型负责「意图规划」与「结论生成」；**所有数值计算在本地 JS 精确执行**，避免算错。未配置 Key 时自动降级为本地规则引擎，功能不受影响。
- **存储**：数据集与配置持久化在浏览器 `localStorage`。

## 运行

静态站点，直接用任意静态服务器打开即可，例如：

```bash
cd data-agent
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

也可直接双击 `index.html` 打开。

## 目录结构

```
data-agent/
├── index.html          # 页面结构与弹窗
├── assets/
│   ├── styles.css      # 样式
│   ├── store.js        # 数据导入、类型推断、本地存储
│   ├── analytics.js    # 本地分析引擎（查询/趋势/异常/对比）
│   ├── llm.js          # 大模型接入与本地规则降级
│   ├── charts.js       # ECharts 图表（CDN 不可达时降级为表格）
│   └── app.js          # 交互编排、历史、配置
├── .gitignore
└── README.md
```

> 图表依赖 ECharts CDN；离线环境下自动降级为明细表，分析功能不受影响。
